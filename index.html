v2.0 Production Architecture

Real-Time Event-Driven Data Warehouse

An enterprise-grade Kimball Star-Schema Analytics Engine built with DuckDB, Supabase PostgreSQL, FastAPI, Machine Learning, and dbt.

⚡

Real-Time Event Ingestion

Automated directory watcher and FastAPI REST endpoints (/api/v1/ingest/*) processing micro-batch order streams into dimensional models.

🏛️

Kimball Star-Schema ELT

SCD Type 2 versioning (dim_customer), point-in-time surrogate key resolution, and automated corrupt row Data Quality filter gates.

🤖

Machine Learning Engine

Customer Churn Risk probability scoring, 3-month AI sales revenue forecasting (Holt-Winters), and Z-score order anomaly detection.

☁️

Supabase Cloud Sync

High-speed background replication daemon synchronizing local DuckDB OLAP tables live to Supabase PostgreSQL Cloud.

🔔

Webhook Alerts

Dispatches real-time Slack and Discord webhook alerts for Data Quality rule violations and high-value VIP transactions.

🧪

dbt Test Suite & Lineage

Automated primary key, foreign key, and non-null test assertions with interactive visual DAG documentation.
